# M5SynthAMY
M5Stack AMY Synth: a 26-Key CoreS3 Instrument

A compact, playable 26-key synthesizer built around M5Stack CoreS3 and the open-source AMY synthesis engine.

M5Stack AMY Synth turns an M5Stack CoreS3 into a self-contained electronic instrument. It combines a 26-key illuminated keyboard, a touch-screen patch interface, physical controls, MIDI input, and a stereo I2S DAC. AMY provides virtual-analog, FM, and PCM synthesis, while the CoreS3 coordinates real-time sound, input scanning, and the user interface.
